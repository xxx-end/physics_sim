光路组成

G₁ 为分光板（A 面半透半反射），G₂ 为补偿板（材料、厚度与 G₁ 完全相同）。 光束①两次穿过分光板，光束②没有穿过，故加入 G₂ 补偿光束①两次穿过分光板形成的附加光程差， 使两束光的光程差与波长无关（这对白光干涉尤为重要）。 M₁' 是 M₁ 经 G₁ 所成的虚像，干涉等效于 M₂ 与 M₁' 间厚度为 d 的空气薄膜干涉。

等倾干涉

δ = 2d·cosθ
明环：δ = kλ ， 暗环：δ = (2k+1)λ/2
中心处 θ=0，δ = 2d 最大，级数 k 最高
当 M₂ 与 M₁ 严格垂直时，观察到一系列明暗相间、内疏外密的同心圆环。 d 减小时中心级数减小，圆环逐个"陷入"中心；d 增大时圆环从中心"冒出"。 d 越大，相邻条纹间距越小，条纹越密。

测量激光波长

每从中心"冒出"或"陷入"一个圆环，d 就增/减 λ/2
Δd = N·λ/2 ⇒ λ = 2Δd / N
M₂ 实际移动 Δd = |x₂ − x₁| / 25（杠杆放大）
记录 M₂ 初位置 x₁，单向转动精调测微头计数 50 环后记录末位置 x₂，即可求出波长。
