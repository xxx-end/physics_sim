串联谐振与幅频特性

Z = √( R² + (ωL − 1/(ωC))² )　　I = U₀ / Z　(2.22.3)
ω₀ = 2πf₀ = 1/√(LC)　(2.22.4)　谐振时 U_L=U_C 反相抵消，Z 最小，I 最大
通频带宽度 Δf = f₂ − f₁　（I 降到 0.707·I_max 的两频率）
Q = U_L/U₀ = (1/ω₀C)/R = √(L/C)/R　(2.22.6)　　Q = f₀/Δf　(2.22.7)

Q 越大，曲线越陡峭、通频带越窄、选频能力越强（图 2.22.3）。
