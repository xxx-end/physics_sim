操作提示

  • 顶角测量（自准直法）：固定望远镜，转动载物台，使三棱镜 AB 面反射的小十字像与分划板"十"叉丝上交点重合，记下游标读数；同理记下 AC 面。
  • 最小偏向角：三棱镜置于载物台，入射角约 60°；缓慢转动载物台，谱线移动方向发生逆转的位置即最小偏向角；在该谱线将发生逆转处固定载物台，用望远镜微调对准谱线中央读数。
  • 移去三棱镜后望远镜对准平行光管（入射光位置），两读数之差即最小偏向角。
  • 重复测量 3 次取平均，可减小随机误差。

思考题

（1）分光计是一种精确测量角度的典型光学仪器，主要由平行光管、望远镜、载物台和读数度盘（游标）四部分组成。

（2）调节望远镜光轴垂直于仪器中心轴的标志：从 AB、AC 两反射面反射回的小十字像均与分划板"十"叉丝上交点重合（各半调节法）。

（3）十字像不清晰→调节目镜（叉丝清晰）再调物镜（调焦）；狭缝像不清晰→调平行光管狭缝前后位置使其成像于望远镜焦平面。

（4）最小偏向角：偏向角随入射角变化存在极小值 δmin，此时光线对称通过棱镜（i₁=i₂）；n 与 δmin、A 的关系即式 (2.29.7)。

（5）应缓慢单向转动载物台，观察谱线移动方向发生逆转的时刻来确定。若偏离真实位置，δmin 偏大，由式 (2.29.7) 算得的 n 偏大，产生系统误差。

背景简介

1814 年，夫琅禾费在研究太阳暗线时改进了观察仪器，设计了由平行光管、三棱镜、望远镜组成的分光计——一种精确测量角度的精密典型仪器。三棱镜是用玻璃或水晶制成的透明三棱柱，是实验中重要的分光元件。利用光线在三棱镜面上折射产生的最小偏向角测量棱镜折射率是一种经典方法，可达较高精度。

三棱镜的色散

三角形 ABC 表示三棱镜横截面，AB 和 AC 是透光的光学表面（折射面），A 为顶角。入射光沿光路折射后从另一侧射出，入射光和出射光之间的夹角即偏向角 δ。由于白光由多种频率的单色光组成，各色光折射率不同，出射光出现不同偏向角：频率越高，偏向角越大，形成红到紫的可见光谱，即三棱镜的色散现象。

最小偏向角法测折射率

对单色光，偏向角 δ = (i₁−r₁)+(i₂−r₂) = i₁+i₂−A。对给定棱镜，A 与其对某单色光的折射率一定，δ 只随入射角 i₁ 变化。对其求导并取 di₁/dδ = −1（极值条件），结合折射定律可证：只有当 i₁ = i₂（光线对称通过棱镜）时偏向角取最小值 δmin，此时：

δmin = 2i₁ − A，i₁ = (δmin + A)/2　(2.29.6)

由 A = r₁+r₂ = 2r₁ 与折射定律 sin i₁ = n sin r₁ 得：

n = sin[(A + δmin)/2] / sin(A/2)　(2.29.7)

只要测得顶角 A 和最小偏向角 δmin，即可求出三棱镜对该单色光的折射率。

实验仪器与注意事项

  • 仪器：汞灯及电源、三棱镜、分光计。
  • 不能用手直接触摸三棱镜反射面。
  • 汞灯紫外线较强、亮度高，不要直接注视汞灯，防止伤害眼睛。
  • 转动部件前先松开止动螺钉，读数前锁紧；游标盘的对称双游标读数可消除偏心差。

实验拓展

玻璃的折射率可以用多种方法和仪器测定。利用分光计不但能直接测出反射角、透明物质的折射角、光栅的衍射角、劈尖的角等，还能间接确定折射率、光波波长、色散率、光栅常量等。此外，分光计还可用作多种光学现象的定性观察（衍射、干涉），检验棱镜的棱角是否合格、玻璃砖两表面是否平行等。
