电桥工作原理

RA、RB（比率臂）、RX（测量臂，待测）、RS（比较臂）构成电桥四臂；1、3 对角间接电源与开关，2、4 对角间接灵敏电流计。平衡时 I_g=0，2、4 两点电势相等，由 IABR_A = IXSR_X 可得：

R_A/R_B = R_X/R_S　（2.23.1）
R_X = (R_A/R_B)·R_S = C·R_S　（2.23.2）

C 称为桥臂比，体现待测电阻与比较臂电阻之间的比例关系。平衡方程可用于估算比较臂理论值 R_S = R_X0·R_B/R_A。

电桥灵敏度

S₁ = Δn/ΔI_g（电流计灵敏度，div/A）
S = Δn/ΔR_S　（2.23.3）

由基尔霍夫定律，电桥灵敏度与电路参数的关系：

S = E·S_i / [(R_X+R_A+R_B+R_S) + (2+R_X/R_S+R_B/R_A)·R_g]　（2.23.4）

S 与桥臂比 C、电源电压 E、电流计灵敏度 S_i 及内阻 R_g 有关。仿真内核采用戴维南等效电路精确求解非平衡电流：I_g = V_th/(R_th+R_g)，V_th = E[R_S/(R_X+R_S) − R_B/(R_A+R_B)]，R_th = R_A∥R_X + R_B∥R_S。

灵敏度引入的误差

规定灵敏电流计 1/10 分度的偏转为平衡判断的分辨界限，则由电桥灵敏度引入的待测电阻不确定度：

σR_X = 0.1·C·ΔR_S/Δn = 0.1·C/S　（2.23.5、2.23.6）

本仿真参数

电流计灵敏度 S_i = 1.0×10⁵ div/A（分度值 10 μA/div），量程 ±60 格（超出打表）；电阻器最小步进 0.1 Ω；待测电阻真值 100 Ω。改变组态后需重新估算赋值、平衡、测灵敏度。
