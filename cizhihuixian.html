磁畴与磁化

铁磁体内部存在自发磁化达饱和的小区域——磁畴（约 10¹²~10¹⁵ 个原子）。无外场时各磁畴取向紊乱、宏观磁效应抵消；外场作用下磁畴磁矩趋于一致排列，物质被磁化。

磁场强度 H 的测定（安培环路定理）

H = N·i₁/L，　i₁ = U_H/R₁　⟹　H = N·U_H/(L·R₁)　（2.26.1~2.26.2）
N=50 匝为励磁绕组，L=60 mm 为平均磁路长度，R₁ 为励磁电流取样电阻。U_H 与 H 成正比，接示波器 X 输入。

磁感应强度 B 的测定（法拉第定律 + RC 积分）

ε = n·dΦ/dt，　B = Φ/S = (1/nS)∫εdt　（2.26.3~2.26.5）
测量绕组 n=150 匝与 R₂、C₂ 串联成积分回路；当 i₂R₂ ≫ Q/C₂ 时 ε≈i₂R₂，得
B = C₂·R₂·U_B/(n·S)　（2.26.10）
U_B 为积分电容 C₂ 两端电压，与 B 成正比，接示波器 Y 输入。屏上 X-Y 合成的轨迹即 B-H 磁滞回线。

基本磁化曲线与磁滞回线

退磁后从 H=0 逐挡增大励磁，各磁滞回线顶点的连线称为基本磁化曲线（起始磁化 Oa→bS：缓慢上升—急剧增长—趋于饱和 Bs）。H_s→0→−H_s→0→H_c→H_s 循环一周，B 沿闭 合回线 SRDS′R′D′S 变化——磁滞回线。H=0 时 B=Br（剩磁）；B=0 时 H=−H_c（矫顽力）。磁滞损耗与回线面积成正比。μ=B/H 随 H 变化，不是常数。
