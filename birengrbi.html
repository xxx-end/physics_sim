实验结论

完成 5 次计时后自动给出结论。

比热容比与自由度（式 2.20.1/2.20.2）

定压比热容 Cp 一般大于定容比热容 CV，比值 γ=Cp/CV>1。由气体运动论，γ 与分子自由度 f 有关：

γ = (f+2)/f　(2.20.2)

单原子气体（Ar、He）f=3 → 1.67；双原子气体（N₂、H₂、O₂、空气）f=5 → 1.40；多原子气体（CO₂、CH₄）f=6 → 1.33。

振动钢球模型（式 2.20.3~2.20.6）

钢球 A（质量 m、半径 r）在玻璃管 B 中，瓶内压强满足力平衡：

p = p₀ + mg/(πr²)　(2.20.3)

注入气体使钢球在小孔上下做简谐振动。设偏离平衡位置 y 时瓶内压力变化 Δp，运动方程为 m·ÿ + πr²Δp = 0。振动很快近似绝热过程，对 pVγ=常数 求导：Δp = −γpΔV/V，ΔV=πr²y，代入得：

m·ÿ + π²r⁴γp·y/V = 0　(2.20.6) —— 简谐振动

比热容比公式（式 2.20.7）

T = 2π√( mV / (γπ²r⁴p) )　→　γ = 64mV / (T²·p·d⁴)　(2.20.7)

测出振动周期 T（计时器测 N=50 个周期总时间 t，T=t/50），代入 m=4g、V=1350cm³、d=10mm、p=1.013×10⁵Pa 即得空气的 γ。

思考与拓展

【思考】①空气中有水蒸气（湿度大）结果如何变化？②振动并非理想绝热过程，测得 γ 偏大还是偏小（热交换使有效过程更接近等温，回复力变小、周期变长 → 测得值偏小）？③注入气体流量对小球运动的影响（流量决定振动中心与振幅，过小不振、过大冲出）？
【拓展】空气比热容比用于保温与散热：大气层温室效应使地球昼夜温差不至过大（月球无大气层温差可达 300℃）；风冷用于发动机、CPU 降温与热能回收。
