刚体模型 3.3 复摆（物理摆）

刚体绕水平轴 O 在重力作用下小角度摆动。周期 T=2π√(I/(mgd))，d 为轴到质心距离。等效摆长 L_eq=I/(md) ≠ d——不能用质心距离当摆长！

核心公式
转动方程：I·θ̈ = −mgd·sinθ
小角度：θ̈ + (mgd/I)·θ = 0
T = 2π√( I / (mgd) )
杆+端质量模型（m₁=1kg 均匀杆）：
I = m₁l²/3 + m₂l²
d = (m₁l/2 + m₂l)/(m₁+m₂)
等效摆长 L_eq = I/((m₁+m₂)d)
直觉误区：把质心到轴距离 d 直接当摆长。复摆周期与质量分布有关，L_eq 可能比 d 大也可能比 d 小。对比读数框中 T 与 T₀（错误算法）的差异。
