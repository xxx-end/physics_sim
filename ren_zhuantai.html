核心公式
无外力矩 → J₁ω₁ = J₂ω₂ = L 恒定
转动惯量（人+哑铃简化）：
J = J_body + 2m·r²（哑铃在距轴 r 处）
收臂 r↓ → J↓ → ω = J₀r₀².../J(r) 升高
动能变化：ΔEk = L²/2·(1/J₂ − 1/J₁) > 0
（人收臂做功转化为转动动能）
