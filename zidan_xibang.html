刚体模型 3.1 子弹打击悬挂细棒

水平飞行的子弹射入一端可绕水平轴自由转动的静止细棒（长 l、质量 M）并留在棒内。碰撞瞬间轴的作用力冲量不可忽略——动量不守恒，只有对转轴的角动量守恒。求碰撞后系统角速度。

核心公式
碰撞瞬间对轴角动量守恒：
m·v₀·l = ( Ml²/3 + m·l² )·ω
→ ω = 3mv₀ / ( (M+3m)·l )
为什么不用动量守恒？
轴对棒有未知冲量 F_axle·Δt ≠ 0
质心速度：v_c = ω·l/2（碰后质心）
直觉误区：套用"动量守恒 m·v₀=(M+m)v"。转轴提供了隐形外冲量，只有角动量守恒可用。子弹位置若不在棒端，把 l 换成打击点距轴距离 d 即可。
