实验原理

扭摆的垂直轴上装有薄片状涡卷弹簧，物体在水平面内转过 θ 角后，在弹簧恢复力矩作用下绕垂直轴作往复扭转运动。

M = −Kθ （胡克定律）　　M = Jβ
β = d²θ/dt² = −(K/J)θ = −ω²θ　⇒　θ = A·cos(ωt+φ)
T = 2π/ω = 2π√(J/K)

测得 T 并已知 J、K 中任一个，即可算出另一个。选用形状规则、密度均匀的塑料圆柱体（理论 J 可精确计算）来标定 K：

K = 4π²·J圆柱 / (T₁²−T₀²)　　J盘 = K·T₀²/(4π²)
待测物（放圆盘上）：J = K·T²/(4π²) − J盘

测金属细杆时不用圆盘而用夹具，需扣除夹具转动惯量：

J细杆 = K·T²/(4π²) − J夹具　（J夹具 = 0.211×10⁻⁴ kg·m²）

理论值公式

塑料圆柱：J = ⅛·m·D̄²
金属圆筒：J = ⅛·m·(D外²+D内²)
金属细杆：J = 1/12·m·L̄²

平行轴定理

两滑块对称置于细杆凹槽、距中心转轴 x 时：

J理论 = J细杆 + J滑块 + J夹具 + 2m滑块·x²

若各 x 处的实验值与理论值相符（J–x² 呈线性、斜率≈2m滑块），则平行轴定理得证。
