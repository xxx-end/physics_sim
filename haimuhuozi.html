载流圆线圈轴线上的磁场

B_X = μ₀NIR² / [2(R²+X²)^{3/2}]　（2.25.1）

方向垂直于线圈平面，按右手定则沿 X 轴正向。X=0 处最大：

B₀ = μ₀NI / (2R)　（2.25.2）

亥姆霍兹线圈（半径=间距=R）

两线圈各 N 匝、串联同向电流 I。线圈圆心处（2.25.4）与轴线中点 P（2.25.5）、P 两侧 R/4 处 Q₁Q₂（2.25.6）：

B_O₁ = 0.6768·μ₀NI/R　　B_P = 0.7155·μ₀NI/R　　B_Q = 0.7125·μ₀NI/R

B_Q₁ 与 B_P 相差不足 0.5%，故 P 点附近轴线上磁场基本均匀；在轴线以外一定范围内也基本均匀——这就是获得匀强磁场的"亥姆霍兹法"。

霍尔效应法与换向法

n 型半导体霍尔元件通工作电流，置于磁场中产生霍尔电压 U_H=K·I·B，"测量"显示值即 B（单位 10⁻⁵ T）。为消除地磁场（~5×10⁻⁵ T）与零漂的影响，将励磁电流换向分别读 B⁺、B⁻：

B = (|B⁺| + |B⁻|) / 2　（2.25.7）

仪器参数：N=640 匝（单只）、R̄=10.0×10⁻² m、两线圈中心距 R=10.0×10⁻² m；励磁电源 0~30 V / 0~0.5 A；测磁范围 0~1999×10⁻⁵ T，分辨率 1×10⁻⁵ T。
